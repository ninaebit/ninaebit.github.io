Cosa succede davvero quando cancelli un file

17/11/2026 · video di 40 secondi

Quando cancelli un file, di norma non sparisce: il sistema lo sposta nel cestino. E anche dopo aver svuotato il cestino, i dati spesso restano sul disco, perché il sistema si limita a segnare quello spazio come libero. Ecco i tre passaggi, dal più semplice al più strano.

Il file finisce davvero nel cestino?

Di norma sì. Quando si cancella un file, il sistema operativo lo sposta prima in una cartella speciale, il cestino, senza eliminarlo. È un piccolo trucco da prestigiatore: il file non è più dove lo cercavi, ma esiste ancora. Questo vale per Windows e macOS quando si cancella da Esplora file o dal Finder. Fanno eccezione la combinazione Maiusc+Canc, la riga di comando e le unità USB o di rete.

Cosa succede quando svuoti il cestino?

Svuotando il cestino, il sistema segna lo spazio occupato dal file come libero. In pratica il file system rimuove o marca la voce del file e libera i blocchi, ma non riscrive i dati. Su un hard disk, quindi, le informazioni restano sul disco finché quello spazio non viene sovrascritto da qualcos'altro.

Si può recuperare un file cancellato?

Spesso sì. I programmi di recupero possono ritrovare i file cancellati finché i dati non sono stati sovrascritti, e questo vale soprattutto per gli hard disk. Sugli SSD il discorso cambia: con il TRIM, i blocchi liberi possono essere cancellati davvero, e quando si prova a recuperare il file è spesso troppo tardi. Il recupero, quindi, è molto meno probabile.

Meglio svuotare subito il cestino o tenerlo pieno?

Tenere il cestino pieno lascia ai file una seconda possibilità: basta un clic per ripristinarli. Svuotarlo subito libera lo spazio, ma non significa che i dati siano spariti all'istante, come si è visto. E voi che abitudine avete? Svuotate il cestino subito o lo tenete pieno?
