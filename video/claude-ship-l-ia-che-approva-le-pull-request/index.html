Claude Ship: l'IA che approva le pull request

25/11/2026 · video di 40 secondi

Sì, un'IA che approva le pull request esiste e si chiama Claude Ship. Lo ha lanciato Anthropic il 23 novembre 2026, in beta, per le organizzazioni Claude Team ed Enterprise con repository GitHub. L'approvazione, però, non è libera: riguarda solo le modifiche di routine e segue le regole scritte dal team.

Che cos'è una pull request?

Una pull request è una proposta di modifica al codice che qualcuno deve controllare prima che entri nel progetto. È un passaggio fondamentale nello sviluppo software, perché serve a individuare errori prima che finiscano nella versione ufficiale. Proprio per questo, però, può diventare un lavoro ripetitivo per chi programma.

Cosa fa Claude Ship?

Claude Ship mette insieme il ruolo del revisore e quello del meccanico. Include Code Review, che controlla le modifiche rispetto al resto del codice e pubblica i risultati. Poi ci sono gli agenti che lavorano sui fix: tra questi, PR Steward cerca di mantenere la pull request "verde", cioè con test e CI superati. Infine, Claude può approvare le pull request, ma solo quelle di routine e secondo le regole che il team scrive nel file .claude/approvals.yml. Per tutti gli altri casi serve la firma di persone indicate.

E se l'IA sbaglia?

È la domanda più importante. Anthropic avverte che l'IA può non vedere bug o falle di sicurezza, quindi le regole del team e il controllo umano restano centrali. Per questo l'azienda consiglia di iniziare in modalità osservazione, per capire come Claude si comporta prima di affidargli delle approvazioni. Va detto che alcune fonti sono discordanti sui dettagli del funzionamento, quindi conviene fare riferimento alle indicazioni ufficiali.

Cosa cambia per chi programma?

Se funzionerà come promesso, chi sviluppa potrebbe dedicare meno tempo ai controlli ripetitivi e più tempo al lavoro che richiede davvero attenzione. Il prodotto è ancora in beta, quindi il suo valore pratico si vedrà con l'uso reale nei team.
